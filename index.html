AUTOSYNTH // HELP

Autosynth is a spatial music sequencer. The music is laid out on a physical track. The speed at which you drive dictates the tempo (BPM) of the music.

View the source code on GitHub

CONTROLS

  • [UP] / [DOWN] : Accelerate / Brake (Controls Tempo)
  • [LEFT] / [RIGHT] : Change Lane (Instrument)
  • [SHIFT] + [LEFT/RIGHT] : Instant double lane jump
  • [SPACE] : Drop a note at current position (WRITE mode)
  • [SPACE] (Hold) : Play synth chords (DRIVE mode)
  • [X] (Hold) : Drive over notes to erase them
  • [D] : Toggle between WRITE and DRIVE modes
  • [1] - [9] : Load pre-composed rhythmic templates
  • [M] / [ESC] : Open Sound Studio (Config)
